# AI Use Disclosure

The team used ChatGPT and Codex as AI coding and writing assistants for brainstorming, code scaffolding, debugging, tests, documentation editing, and data-contract review.

Team members selected the scope and method, obtained the NASA FIRMS data, reviewed generated code, ran tests and production builds, checked claims against exported data, and approved the final interface and submission materials.

AI did not generate or modify the NASA observations. FireLens uses deterministic calculations and templates for displayed evidence and readiness language; a generative model does not make operational fire decisions.

No AI-generated image, video, or audio is included in the web application. Any later AI-generated demonstration media must be visibly labeled and disclosed.
